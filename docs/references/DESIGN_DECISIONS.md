Originally: **Thesis reframed to two CO-EQUAL engines** (lean-prd, "FollowThru partners with you (two engines)"): **Remembering** (RTA — a distinctive cue surfaces the intention at the moment) × **Wanting** (intrinsic motivation, Fishbach — harness what's rewarding across BOTH want-to and have-to goals; want-to slightly prioritized, have-to harnessed not dismissed), **fused** in the reminder that "hands the want-to back to you" right when you'd act. FollowThru **partners** — it never fights, battles, or nags. Shapes: positioning (partnership + want-to, never willpower/streaks), goal flow (capture + seed "the most enjoyable way to do it"), reminder voice (partnering, never coercive, always declinable), progress framing (forgiving + celebratory, never a scoreboard). Intrinsic motivation is now co-central with RTA, NOT a roadmap add-on (supersedes the standalone "Intrinsic-Motivation Principle" section, folded into the thesis).
- 2026-06-14 — **Intrinsic motivation is goal-DESIGN, not a reminder input** (thesis re-reframed, lean-prd "## Thesis"). FollowThru does two *partnering* jobs: (1) help build goals worth pursuing — find/build the want-to, reframe a have-to toward a way you'd enjoy, connect it to the user's About You passions/interests, choose the path that pulls; and (2) RTA — a single distinctive cue reminds at the moment. The wanting lives in the **goal**; it is **never** funneled into the cue or the implementation intention — the reminder carries the user's own intention as written. Removes the prior `enjoyableWay` goal field that seeded the builder's "I will" (and its DB v37 migration; the implementation intention itself is left untouched). Supersedes the same-day "two co-equal engines fused in the reminder" thesis entry and the "Goal creation captures the intrinsic *way*" field entry above. How the goal-creation flow should build intrinsic motivation is a separate proposal — `docs/references/goal-design-proposal.md`, **propose-only, nothing built yet**.
- 2026-06-14 — **ANDROID_HANDOFF.md reconciled to the two-jobs thesis** — added a "Product thesis (two jobs)" note up top and removed the `enjoyable_way` goal field + its "seeds the intention's 'I will'" description from §3 (data model + field-driven-UI list) and §9.2 (vocabulary), matching the reverted app (DB back to v36) and lean-prd "## Thesis"; recorded as handoff §10 item 6. **No replacement goal-design mechanism was invented** — each removal site points to the open proposal (`docs/references/goal-design-proposal.md`); the goal-design layer remains undecided.
